# AI-Powered Student Performance Analytics System

An interactive analytics platform that combines a synthetic student marks dataset with a real Virtual Learning Environment (VLE) dataset to predict academic performance and identify at-risk students.

## Features

- **Marks regression** — predict 2026 subject marks per student using Linear Regression, Decision Tree, and Random Forest models
- **Pass/Fail classification** — classify VLE students as pass or fail using Logistic Regression and Random Forest (SMOTE-balanced training)
- **Statistical analysis** — subject summaries, top performers, year-on-year change, correlation matrix
- **Interactive dashboard** — Streamlit app with cohort overview, student profiles, 2026 predictions, and VLE at-risk predictor
- **PDF report** — auto-generated multi-page report with charts, tables, and per-student pages

## Datasets

| Dataset | Description |
|---------|-------------|
| Synthetic cohort | 15 students × 5 subjects × 2 years (2024–2025) with 2026 predictions |
| Real VLE dataset | 160 student instances × 19 features (pass/fail classification) |

## Setup

```bash
git clone https://github.com/Faris075/software-testing-project.git
cd software-testing-project
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## Running the Pipeline

```bash
# 1. Seed the database and generate students_raw.csv
python database/seed.py

# 2. Clean and preprocess data → students_clean.csv
python preprocessing/clean.py

# 3. Train all models (regression + VLE classifiers)
python models/train.py

# 4. Launch the dashboard
streamlit run dashboard/app.py
```

## Project Structure

```
├── data/
│   ├── students_raw.csv          # generated by seed.py
│   ├── students_clean.csv        # generated by clean.py
│   └── vle/                      # real VLE dataset (original, test, SMOTE variants)

├── preprocessing/
│   └── clean.py                  # missing value imputation, outlier clipping, normalisation
├── analysis/
│   └── stats.py                  # subject summary, top performers, YoY change, correlation
├── visualisation/
│   └── charts.py                 # all matplotlib/seaborn chart functions
├── models/
│   ├── train.py                  # train regression + VLE classifier models
│   ├── predict.py                # inference functions
│   └── evaluate.py               # RMSE, MAE, ROC-AUC, recall_fail metrics
├── saved_models/                 # .pkl files (gitignored)
├── report/
│   └── generate_pdf.py           # ReportLab PDF builder
├── dashboard/
│   └── app.py                    # Streamlit entry point
├── tests/                        # pytest test suite (38 tests)
└── outputs/
    ├── charts/                   # saved chart PNGs (gitignored)

```
